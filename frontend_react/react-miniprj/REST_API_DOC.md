# 📚 게시판 서비스 REST API 명세서

네이버 오픈 API 명세 형식을 기반으로 작성된 게시판 프로젝트의 REST API 문서입니다.

---

## 1. 회원 관리 API (Member)

### 1.1 회원가입

#### 설명
신규 회원 정보를 등록합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/mem
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`POST`

#### 파라미터 (Request Body)
요청 본문(Body)을 JSON 형식으로 전달합니다.

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `mem_id` | String | Y | 회원 로그인 아이디 |
| `pwd` | String | Y | 회원 비밀번호 |

#### 응답 예
```json
{
  "id": "i_V8dKtEdK4",
  "mem_id": "121212",
  "pwd": "222"
}
```

---

### 1.2 회원 목록 및 로그인 조회

#### 설명
등록된 회원 목록을 조회하거나 특정 회원의 정보를 조회하여 로그인을 검증합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/mem
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`GET`

#### 파라미터 (Query String)
파라미터를 쿼리 스트링 형식으로 전달할 수 있습니다. (생략 시 전체 회원 목록 반환)

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `mem_id` | String | N | 조회할 회원 아이디 |

#### 응답 예
```json
[
  {
    "id": "1",
    "mem_id": "홍길동",
    "pwd": "1234"
  },
  {
    "id": "2",
    "mem_id": "이순신",
    "pwd": "5678"
  },
  {
    "id": "i_V8dKtEdK4",
    "mem_id": "121212",
    "pwd": "222"
  }
]
```

## 2. 게시글 관리 API (Board)

### 2.1 게시글 목록 조회

#### 설명
등록된 모든 게시글 목록을 조회합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/boards
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`GET`

#### 파라미터
없음 (전체 목록 반환)

#### 응답 예
```json
[
  {
    "id": "1",
    "title": "첫 번째 게시글",
    "text": "안녕하세요. 첫 번째 게시글입니다.",
    "mem_id": "홍길동",
    "reg_dtm": "2025-01-01",
    "mod_dtm": "2025-01-02",
    "count": 0
  },
  {
    "id": "2",
    "title": "두 번째 게시글22",
    "text": "안녕하세요.22 두 번째 게시글입니다.",
    "mem_id": "이순신",
    "reg_dtm": "2025-01-03",
    "mod_dtm": "2026-09-23",
    "count": 0
  }
]
```

---

### 2.2 게시글 상세 조회

#### 설명
게시글의 고유 식별자(`id`)를 통해 특정 게시글 1건의 상세 정보를 조회합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/boards/{id}
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`GET`

#### 파라미터 (Path Variable)
URL 경로에 게시글의 고유 ID를 전달합니다.

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `id` | String | Y | 조회할 게시글의 고유 ID |

#### 응답 예
```json
{
  "id": "1",
  "title": "첫 번째 게시글",
  "text": "안녕하세요. 첫 번째 게시글입니다.",
  "mem_id": "홍길동",
  "reg_dtm": "2025-01-01",
  "mod_dtm": "2025-01-02",
  "count": 0
}
```

---

### 2.3 게시글 등록

#### 설명
새로운 게시글을 작성하여 등록합니다. (`id`는 서버에서 고유값 자동 발급)

#### 요청 URL
```http
http://192.168.0.185:3000/boards
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`POST`

#### 파라미터 (Request Body)
요청 본문(Body)을 JSON 형식으로 전달합니다.

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `title` | String | Y | 게시글 제목 |
| `text` | String | Y | 게시글 본문 내용 |
| `mem_id` | String | Y | 작성자 회원 아이디 |
| `reg_dtm` | String | Y | 게시글 최초 등록일자 (`YYYY-MM-DD`) |
| `mod_dtm` | String | N | 게시글 최종 수정일자 (`YYYY-MM-DD`) |
| `count` | Integer | N | 조회수 (기본값: `0`) |

#### 응답 예
```json
{
  "id": "q7oyWXbkGxg",
  "title": "안녕하세요",
  "text": "새로 작성한 글 내용입니다.",
  "mem_id": "이순신",
  "reg_dtm": "2026-09-23",
  "mod_dtm": "",
  "count": 0
}
```

---

### 2.4 게시글 수정

#### 설명
기존 게시글의 제목, 내용, 최종 수정일자 등을 변경합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/boards/{id}
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`PATCH`

#### 파라미터 (Path Variable 및 Request Body)
- **Path Variable**

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `id` | String | Y | 수정할 게시글의 고유 ID |

- **Request Body (JSON)**

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `title` | String | N | 변경할 제목 |
| `text` | String | N | 변경할 본문 내용 |
| `mod_dtm` | String | Y | 최종 수정일자 (`YYYY-MM-DD`) |

#### 응답 예
```json
{
  "id": "2",
  "title": "두 번째 게시글22",
  "text": "안녕하세요.22 두 번째 게시글입니다.",
  "mem_id": "이순신",
  "reg_dtm": "2025-01-03",
  "mod_dtm": "2026-09-23",
  "count": 0
}
```

## 3. 댓글 관리 API (Reply)

### 3.1 특정 게시글의 댓글 목록 조회

#### 설명
특정 게시글(`board_id`)에 달린 댓글 목록을 조회합니다.

#### 요청 URL
```http
http://192.168.0.185:3000/reply
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`GET`

#### 파라미터 (Query String)
파라미터를 쿼리 스트링 형식으로 전달합니다.

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `board_id` | Integer / String | Y | 댓글을 조회할 게시글 번호 |

#### 응답 예
```json
[
  {
    "id": "1",
    "board_id": 1,
    "mem_id": "이순신",
    "reply": "첫 번째 글 유익하네요! 잘 읽었습니다.",
    "del_flg": "N",
    "reg_dtm": "2025-01-01 10:15:00"
  },
  {
    "id": "2",
    "board_id": 1,
    "mem_id": "홍길동",
    "reply": "감사합니다. 좋은 하루 보내세요!",
    "del_flg": "N",
    "reg_dtm": "2025-01-01 11:20:00"
  }
]
```

---

### 3.2 댓글 등록

#### 설명
특정 게시글에 새로운 댓글을 작성하여 등록합니다. (`id`는 서버에서 고유값 자동 발급)

#### 요청 URL
```http
http://192.168.0.185:3000/reply
```

#### 프로토콜
`HTTP`

#### HTTP 메서드
`POST`

#### 파라미터 (Request Body)
요청 본문(Body)을 JSON 형식으로 전달합니다.

| 파라미터 | 타입 | 필수 여부 | 설명 |
|---|---|:---:|---|
| `board_id` | String / Integer | Y | 댓글을 작성할 게시글의 고유 ID |
| `mem_id` | String | Y | 댓글 작성자의 회원 아이디 |
| `reply` | String | Y | 댓글 본문 내용 |
| `del_flg` | String | N | 삭제 여부 플래그 (기본값: `"N"`) |
| `reg_dtm` | String | Y | 댓글 최초 등록일자 (`YYYY-MM-DD`) |

#### 응답 예
```json
{
  "id": "4FfF1I07Kjg",
  "board_id": "piWXQV9fJw4",
  "mem_id": "121212",
  "reply": "ㅋㅋㅋㅋㅋㅋㅋㅋㅋㅋ",
  "del_flg": "N",
  "reg_dtm": "2026-09-23"
}
```
